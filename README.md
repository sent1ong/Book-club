# BOOK CLUB 98

Next.js 기반 모임 독서 기록 사이트입니다.

## 파일 배치

```text
app/
  page.tsx             화면 구성과 기능 연결
  layout.tsx           공통 레이아웃
  globals.css          공통 스타일
  reviews/             리뷰 카드·서식·입력·작품 통계
  community/           이의 제기·최종 변론·증인·공동책장
  pets/                펫 표시·성장·일기·캐시·돌봄 시각
  desktop/             테마·시작 메뉴·커서·효과음
  bingo/               빙고 상태와 저장
  games/               퀴즈·키워드 가챠
  awards/              결산·상장
  ui/                  창 닫기·ESC·저장 안내
  data/                목록 캐시·행 재사용
  security/            서버 인증·조회 정책·클라이언트 통신
  api/                 서버 API
  pwa/                 모임별 설치 경로
public/
  pets/                펫 이미지
  cursors/             커서 원본·프레임·manifest
  icons/               아이콘
```

기능별 파일은 폴더 안에 두고, Next.js 진입점은 기존 위치를 유지합니다.
서버 전용 코드와 브라우저 코드를 한 파일로 합치지 않습니다.

## 로컬 실행과 확인

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

배포 환경 변수는 기존 프로젝트 설정을 사용합니다. `.env`·비밀키·Vercel 환경 변수 값을 저장소나 공유 ZIP에 넣지 않습니다.
이 저장소의 서버 API는 기존 Supabase 테이블·함수가 이미 구성된 운영 환경을 전제로 합니다. 프런트 파일을 정리한다고 테이블명이나 저장된 기록을 바꾸지 않습니다.

## 정리 버전 적용 시 주의

파일을 이동한 버전이므로 새 파일을 추가 업로드하는 것만으로는 정리가 끝나지 않습니다. 이전 위치의 파일은 함께 제거되어야 합니다. 특히 예전 `app/DesktopTheme.tsx` 등은 오래된 상대 경로를 참조할 수 있습니다.

로컬 Git 저장소에서 기존 `app` 폴더를 이 버전의 `app` 폴더로 교체하고, `public/pets`의 압축된 이미지를 덮어쓴 뒤 추가·수정·삭제를 하나의 커밋으로 반영하는 방식을 권장합니다. 새 ZIP을 저장소 안에 업로드하는 방식은 사용하지 않습니다.

커서 원본·manifest·프레임은 연결된 자료이므로 이름이 비슷하거나 픽셀이 같다는 이유만으로 임의 삭제하지 않습니다.
